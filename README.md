# Blogify 📝

Blogify is a lightweight and responsive blogging platform built with **Node.js, Express, MongoDB, and EJS**.  
It allows users to create, share, and explore blog posts with cover images, formatted text, and interactive comments.

---

## 🚀 Features
- User authentication with JWT
- Create, edit, and delete blog posts
- Upload cover images for blogs
- Comment system for user interaction
- Responsive UI with Bootstrap
- Clean card‑based layout for consistent alignment

---

## 📂 Project Structure
BLOGIFY/
├── app.js                # Main application entry
├── models/               # Mongoose models (User, Blog, Comment)
├── routes/               # Express routes (blog, user)
├── middlewares/          # Authentication middleware
├── services/             # JWT authentication service
├── views/                # EJS templates (home, blog, addBlog, signin, signup)
├── public/               # Static files (images, uploads)
├── .env                  # Environment variables
├── package.json          # Dependencies and scripts
